# vibecoder-demos

Работы для портфолио на Вайбкодере. Каждая — отдельная папка и самостоятельный продукт, которым можно пользоваться, а не макет.

| Папка | Категория | Что это | Демо |
|---|---|---|---|
| [`landing/`](landing) | Сайты и лендинги | Одностраничник-шаблон для местной мастерской: услуги с ценами, «открыто сейчас» по часам работы, расчёт стоимости, заявка в Telegram или на почту. Всё содержимое — в одном файле `config.js`. | `/landing/` |
| [`habits/`](habits) | Веб-приложения | Трекер привычек: отметки по дням, серии, история за 12 недель, перенос данных файлом. Без регистрации — данные только в браузере. | `/habits/` |
| [`qr/`](qr) | Инструменты для продуктивности | Генератор QR-кодов для ссылок, Wi-Fi и визиток, с выгрузкой в PNG и SVG. Считается в браузере, на сервер ничего не уходит. | `/qr/` |
| [`scripts/linkcheck/`](scripts/linkcheck) | Скрипты | Утилита командной строки: находит мёртвые ссылки в Markdown и HTML, пригодна для CI. Один файл на Python без зависимостей. | нет — это CLI |
| [`bot/`](bot) | Боты | Место зарезервировано, ждёт токен. | — |

## Как устроено

Всё статическое: HTML, CSS и JavaScript без сборки. Один проект на Vercel отдаёт корень репозитория, каждое демо — на своём пути (`/landing/`, `/habits/`, `/qr/`).

Локально:

```
python3 -m http.server 8000
# http://localhost:8000/landing/
```

У каждой работы свой внешний вид — это разные задачи, и выглядеть одинаково они не должны.
