# linkcheck

Находит мёртвые ссылки в документации: README, вики, статических сайтах. Проходит по Markdown- и HTML-файлам, проверяет каждую ссылку и печатает только битые — с файлом и номером строки.

```
$ python3 linkcheck.py docs/
docs/install.md:14: https://example.org/old-page — HTTP 404
docs/index.md:3: img/schema.png — файл не найден
файлов: 12, уникальных веб-ссылок: 48, битых: 2
```

Код выхода — `1`, если нашлась хоть одна битая ссылка, иначе `0`. Поэтому скрипт можно поставить шагом в CI: сборка документации упадёт раньше, чем читатель наткнётся на 404.

## Установка

Не нужна. Один файл, только стандартная библиотека Python 3.8+.

```
curl -O https://raw.githubusercontent.com/Gerazi/vibecoder-demos/main/scripts/linkcheck/linkcheck.py
python3 linkcheck.py --help
```

## Что проверяется

- ссылки Markdown `[текст](адрес)`, сноски `[id]: адрес`, картинки `![](адрес)`;
- атрибуты `href` и `src` в HTML;
- голые `http(s)://` ссылки в тексте;
- относительные ссылки на файлы — существует ли файл рядом.

Не проверяются: `mailto:`, `tel:`, якоря `#раздел` и всё внутри блоков кода ```` ``` ````.

Каждая веб-ссылка проверяется один раз, даже если встречается в десяти файлах. Сначала запросом `HEAD`; если сервер его не принимает — `GET` с чтением только начала ответа. Ответ `429 Too Many Requests` битой ссылкой не считается.

## Параметры

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `paths` | `.` | файлы или папки; в папках — `.md`, `.markdown`, `.mdx`, `.html`, `.htm` |
| `--timeout` | `10` | сколько секунд ждать одну ссылку |
| `--workers` | `8` | сколько ссылок проверять параллельно |
| `--ignore REGEX` | — | пропускать ссылки, подходящие под выражение, например `'localhost\|staging\.'` |
| `--no-web` | — | только ссылки на файлы, без сети — быстро, для pre-commit |
| `--json` | — | отчёт в JSON: `{"files", "web_links", "broken": [{"file", "line", "url", "reason"}]}` |

Папки `.git`, `node_modules`, `venv`, `dist`, `build`, `.next` пропускаются.

## В CI (GitHub Actions)

```yaml
- name: Проверить ссылки в документации
  run: python3 scripts/linkcheck/linkcheck.py docs README.md --timeout 15
```
